# Колесо выбора

Веб-приложение для случайного выбора с помощью одного, двух, трёх или четырёх настраиваемых колёс.

## Возможности

- выбор от одного до четырёх колёс;
- редактирование названий и вариантов;
- личные и общедоступные наборы в Cloud Firestore;
- вход через Google;
- добавление локальных изображений к вариантам.

Изображения пока хранятся только локально в течение работы страницы и не загружаются в облако.

Проект создан для сообщества [Türkçe Materyaller](https://vk.ru/turkcemateryaller).
